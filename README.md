# Assignment 19: Mobile App

This branch contains the mobile app submission for Assignment 19.

## Contents
- mobile/App.tsx
- mobile/app.json
- mobile/package.json
- mobile/package-lock.json
- mobile/tsconfig.json
- mobile/assets/

## How to Run
From the mobile folder, install dependencies and start Expo:

```bash
npm install
npm start
```

## Notes
Generated Expo cache files are intentionally excluded. The branch keeps the source app files and assets needed for the assignment.
